# erp-order-import

En liten integrasjonsløsning som importerer ordrer fra et simulert ERP-system,
validerer dem og lagrer dem i MongoDB. Resultatet skal vises i en Angular-app.

**Status:** Under arbeid.

## Teknologi
- C# / ASP.NET Core Web API (.NET 10)
- MongoDB 7 i Docker
- Angular

## Kjøre databasen
docker compose up -d
